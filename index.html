ISK PostgreSQL Backup

ISK PostgreSQL Backup is a private backup utility designed to protect PostgreSQL databases.

Purpose

The application creates database backups and securely stores encrypted copies in the owner's Google Drive account using rclone.

Google Drive Access

Google Drive access is used exclusively to upload, verify, and restore backup files managed by the application.

Backup files are encrypted locally before being transferred to Google Drive.

Privacy

The application is intended for private use. It does not sell personal information or share Google account data with advertisers.
